（ **2** ） **MOE** 架构提升模型效率

**MoE** 架构每次激活部分参数，降低计算成本。 MoE 通过“稀疏激活”机制，将

模型总参数拆分为多个专家网络，并由路由器根据输入 token 动态选择部分专家
参与计算，从而实现“总参数”与“实际计算成本”的解耦。Switch Transformer

于 2021 年在万亿参数级模型上验证该思路；据 SemiAnalysis 等第三方机构估
算，GPT-4 也采用约 1.8 万亿总参数的 MoE 架构，推动 MoE 成为前沿模型

的重要技术路线。


**MoE** 架构的核心特征在于“参数规模大、单次激活少”。 从图 2 中可以看到，

深蓝色表示高激活频率，浅色表示低激活频率，在不同语料和语言任务中，每次

推理仅有部分专家网络被明显激活，绝大多数专家保持低频调用。

### 1.3 推理：从训练时算力到推理时算力


大模型推理能力提升依靠 **CoT** 、 **test-time compute scaling** 、强化学习与长上下
文能力。


 **CoT** （ **Chain-of-Thought** ，思维链）是推理能力提升的关键机制。 2022 年 1

月，Google Brain 等研究者提出 Chain-of-Thought Prompting，首次系统证明
通过生成中间推理步骤可显著提升大模型在数学、常识和符号推理任务上的
表现。与普通提示词不同，推理模型中的 CoT 不再只是外部 prompt 技巧，

而逐步成为模型内部推理过程和后训练目标的一部分。


 **Test-time compute scaling** 将推理阶段转化为新的可扩展计算资源。 传统模

型在推理阶段主要完成一次前向传播，而推理模型可以在输出答案前投入更

多 token 和算力，展开更长思考链，并进行多轮校验、回溯修正和答案优化。


 强化学习是训练模型“学会推理”的基础范式。 尤其在数学、代码等具备客
观反馈的任务中，模型可以通过奖励信号优化解题策略和自我校正能力。由


此，模型能力提升不再只依赖训练阶段的参数、数据和算力扩张，推理阶段

本身也成为新的 scaling 维度。


 长上下文能力是大模型推理能力提升的核心基础 。通过 KV Cache 及显存管
理优化复用历史 token 的 Key/Value 状态，降低长序列生成过程中的重复

计算和推理成本，使模型能够在同一上下文窗口内处理长文档、多文件代码

库、多轮对话和复杂约束条件。

（ **2** ）驾驭工程（ **Harness Engineering** ）

**Agent** 工程范式正从提示词工程、上下文工程演进至驾驭工程。 代码执行提供了

最早成熟的可验证环境，但真实工程任务远高于单次代码生成或测试通过。模型

要在长周期任务中稳定交付，需要持续理解目标、管理上下文、拆解步骤、观察

执行结果，并在出错后自动修正。提示词工程解决“如何提出指令”，上下文工

程解决“提供哪些有效信息”，Harness Engineering 则解决“如何让 Agent 在复

杂任务中持续、稳定、可验证地运行”。


**Harness Engineering** 的核心是为 **Agent** 设计可控、可验证、可纠错的运行环境 。
2026 年 2 月，OpenAI 首次在官方博客中提出 Harness Engineering，强调通过上

下文管理、架构约束和反馈机制，使 Codex Agent 能在真实软件工程中持续执行、
验证和修正。其内部实验中，少数工程师通过提示词与反馈驱动 Codex，在约 5

个月内完成百万行代码级产品开发。2026 年 3 月，Anthropic 提出 Harness design，

通过多 Agent 架构、Sprint Contract 和上下文重置等机制，提升 Claude 在长程自
主开发任务中的完成度和稳定性。


**Harness** 是当前 **Agent** 工程的“集大成者”，涵盖所有围绕大模型构建的工程

化执行系统。 基于提示词、上下文到驾驭工程的方法论演进，LangChain 采用

Harness = Agent - LLM 公式，将 Harness 提炼为 Agent 除模型外一切使之具备
任务执行能力的配套，即让 Agent 稳定运行的环境工程。

### 投资建议


全球大模型产业技术高频迭代，今年开始全面商业化提速，会员订阅转化随模型

能力提升而加速，Coding 与 Agentic 场景落地驱动 API 调用激增，生态赋能逐

步实现多维度全方面变现，大模型本身成为成长最快的赛道，从“吞金兽”转变

为“印钞机”的奇点临近。


AI 算力基础设施是大模型发展的基本保障，成为制约大模型能力迭代和收入放
量的关键因素；AI Infra 及 MaaS 云服务厂商助力 AI 算力和应用场景落地效率提

升，也将持续分享 AI 产业成长红利。

### 风险提示


前沿技术路线收敛缓慢及工程化落地不及预期风险： 尽管大模型与 Agent 架构持
续迭代，但底层技术路线尚未完全收敛，不同厂商在训练策略、评测标准及多模


态对齐方法上存在显著差异。若核心算法在复杂业务场景下的稳定性、长上下文

推理效率或自主规划能力未能如期突破，可能导致产品体验与商业化预期出现落
差。此外，从实验室 Demo 到工业级高可用系统的工程化转化周期较长，数据治

理、系统耦合及算力调度等环节的瓶颈可能拖慢整体产业化节奏，使得技术红利


向生产力转化的效率不及市场乐观预期。


企业端 **AI** 预算释放迟缓及合规风险： 企业对数据隐私、系统安全性要求极高，
若 AI Agent 在核心业务流中的容错率未达预期，可能导致企业端 AI 采购预算释

放滞后。此外，AI 生成内容的版权争议、数据确权及多国监管合规政策的变化，

均可能对行业发展造成阶段性扰动。
